# 需求文档：图片去水印工具

## 产品概述
一个运行在网页上的图片去水印工具，手机和电脑均可使用。用户上传带水印的图片，手动标记水印位置，AI自动填充去除水印，不降低原图画质，最后提供下载。

## 用户故事
1. 用户打开网页 → 看到上传区域 → 点击上传或拖拽图片
2. 图片显示后 → 用手指/鼠标涂鸦标记水印位置 → 看到红色半透明标记
3. 点击"去水印" → AI自动填充标记区域 → 预览效果
4. 满意则点击"下载" → 保存无水印图片到设备
5. 不满意可撤销、擦除、重新标记

## 功能需求
### 核心
- F1: 支持上传 JPG、PNG、WebP 格式图片
- F2: 自由涂鸦标记水印区域，可调节笔刷大小
- F3: 自动填充标记区域（AI inpainting）
- F4: 下载处理后的图片（PNG无损格式）
- F5: 全浏览器端处理，图片不上传服务器

### 交互
- F6: 撤销上一步涂鸦
- F7: 橡皮擦模式（擦除部分标记）
- F8: 清除全部标记
- F9: 前后对比切换

### 体验
- F10: 移动端手指触控正常绘制
- F11: 加载状态提示
- F12: 错误提示（非图片文件、文件过大等）

## 非功能需求
- NF1: 手机和桌面端均可使用（响应式布局）
- NF2: 非水印区域画质无损
- NF3: 淡粉色主题 (#f9a8d4 为主色调)
- NF4: 界面简洁直观
- NF5: 首次加载 ≤ 15秒（含OpenCV.js），后续访问 ≤ 3秒
