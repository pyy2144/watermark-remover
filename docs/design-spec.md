# 设计规范：图片去水印工具

## 色彩系统
```css
--pink-50:  #fdf2f8   /* 背景浅粉 */
--pink-100: #fce7f3   /* 卡片背景 */
--pink-200: #fbcfe8   /* 边框 */
--pink-300: #f9a8d4   /* 次要按钮 */
--pink-400: #f472b6   /* 主按钮hover */
--pink-500: #ec4899   /* 主按钮 */
--pink-600: #db2777   /* 文字强调 */
--gray-50:  #fafafa   /* 页面背景 */
--gray-800: #1f2937   /* 正文文字 */
--white:    #ffffff
```

## 排版
- 字体：系统默认（-apple-system, sans-serif）
- 标题：1.5rem，加粗
- 正文：1rem，行高 1.6
- 小字/提示：0.875rem

## 布局
- 最大内容宽度：960px，居中
- 卡片圆角：12px
- 卡片阴影：0 2px 12px rgba(0,0,0,0.08)
- 移动端断点：768px（以下堆叠布局）
- 按钮最小触控区域：44px × 44px

## 组件规范
### 上传区
- 虚线边框，2px dashed var(--pink-300)
- 背景 var(--pink-50)
- 内边距 40px
- 悬停时边框变实线，背景加深

### 按钮
- 主按钮：var(--pink-500) 背景，白色文字
- 次要按钮：白色背景，var(--pink-300) 边框
- 禁用态：灰色背景，降低透明度
- 圆角 8px

### 画布区
- 原图/结果两栏并排（桌面端）
- 堆叠（移动端）
- 标记叠加层：红色半透明 rgba(255, 0, 0, 0.3)
